and outreach infrastructure built from real campaigns.

No theory. No generic advice. Everything here has been used 
across early-stage SaaS products and B2B outreach at some point.

Founders doing their own outreach.  
Marketers building systems without a full team.  
Anyone tired of paying for five tools that don't talk to each other.

## How to Use These Skills

Each skill is a standalone `.md` file.  
Open it, read the workflow, follow the stages.  
Some parts are fully guided. Some parts you'll need to adapt 
to your specific ICP and offer.

They're not plug-and-play templates.  
They're documented systems — the kind you'd normally figure out 
the hard way over three failed campaigns.
